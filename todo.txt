
  Recommended Layout

  1. Home / Today
     Show what the user needs to do now:

  - Today’s scheduled audits
  - Assigned outlet / zone / room
  - Pending uploads
  - Failed or critical findings
  - Quick buttons: Start Inspection, Scan QR, Upload Photo, Continue Draft

  This matches the meeting point that inspections should happen on-site, by
  zone, with immediate photo upload.

  2. Inspections
     This should be the main working area:

  - Business Unit: Loudspeaker, Mini Studio
  - Outlet
  - Zone / Room / Location
  - Checklist sections
  - Score/status per item
  - Photo evidence per issue
  - Save draft / submit / generate report link

  The meeting notes mention zone-based inspections, physical vs system-record
  checking, and red/yellow/green equipment health. That belongs here.

  3. Work Orders
     Separate audit findings from follow-up actions:

  - New issue from inspection
  - Priority: High / Medium / Low
  - Request type: SSD, CLD, IT, Event, etc.
  - Status: Assigned, Investigation, Repairing, Verification, Closed
  - Outlet confirmation required

  This reflects the CMMS workflow discussion. Right now “KPI & Follow-up” is too
  vague for this.

  4. Equipment
     Add a proper equipment/location registry:

  - QR code / asset ID
  - Outlet / zone / room
  - Equipment type: UPS, CCTV, server, speaker, display, etc.
  - Health: Normal / Monitor / Replace
  - Last checked
  - Replacement budget flag

  The notes strongly point to QR scanning, equipment health, and long-term
  replacement planning.

  5. Reports
     Move leaderboard/charts here:

  - Outlet ranking
  - Score trends
  - Critical issues
  - Export inspection report
  - Photo evidence summary
  - Monthly audit report

  This keeps analytics away from the field workflow.

  6. Admin / Settings
     For setup:

  - Business units
  - Outlets
  - Zones / rooms
  - Checklist templates
  - Request categories
  - Users / roles
  - PINs / captain assignment

  Main Navigation I’d Use
  For web desktop:

  Today | Inspections | Work Orders | Equipment | Reports | Admin

  For Android mobile:

  Bottom nav:
  Today | Inspect | Issues | Equipment | Reports

  Primary action button:
  Scan QR or Start Inspection

  Biggest Improvement
  The current app is dashboard-first. I’d make it task-first:

  When staff open the app, they should immediately see:

  - What outlet/zone needs checking
  - What checklist to complete
  - What photos are missing
  - What issues need follow-up

  Dashboard and leaderboard are useful, but they should support management after
  data is collected. The field user needs a clean guided flow first.
