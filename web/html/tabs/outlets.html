How Outlets Work

Outlets control the locations users can select when scheduling visits, running inspections, registering equipment, and reviewing reports.

Outlet Code
The short store or branch code used across inspections, schedules, equipment, and reports.
Outlet Location
Where the outlet is located, such as the mall, branch area, city, or floor.

How Zones Work

Zones group multiple locations under one inspection area so staff can inspect by area instead of choosing locations one by one.
