Categories

How Categories Work

Categories describe the type of issue found during an inspection. They help users classify findings consistently and make reports easier to group by issue type.

Name
The category shown when creating a finding or work order.
Department
The department that normally handles findings in this category. It is filled in for each new finding and can be changed there.
Sequence
Controls the display order. Lower numbers appear first.
Active
Inactive categories remain saved for reference but are hidden from selection lists.
